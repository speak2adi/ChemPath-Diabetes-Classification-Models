\# ChemPath-Diabetes-Classification-Models



\## Project Overview



This repository documents my implementation of multiple supervised machine learning classification models using the Pima Indians Diabetes Dataset. The objective is to understand how different classification algorithms behave when trained and evaluated on the same dataset.



Each model is trained under similar conditions to enable a fair comparison of their performance and decision-making approaches.



\---



\## Objectives



\- Understand the theory behind different classification algorithms.

\- Compare multiple models using the same dataset.

\- Evaluate models using appropriate classification metrics.

\- Develop practical machine learning skills with Python and Jupyter Notebook.



\---



\## Dataset



\- \*\*Dataset:\*\* Pima Indians Diabetes Dataset

\- \*\*Task:\*\* Binary Classification

\- \*\*Target Variable:\*\* Outcome

&#x20; - 0 = Non-diabetic

&#x20; - 1 = Diabetic
